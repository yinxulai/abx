# source/ —— 面向使用者的文档（尚未开写）

这里放**给使用者看的**文档：怎么装、怎么第一次跑起来、托盘怎么用、出问题了怎么办。
未来按 osw 的做法分 `zh/` 与 `en/` 两个语言目录，按 tab 分子目录，发布成静态站。

**和 `specs/` 的区别：**

| | `specs/` | `source/` |
|---|---|---|
| 读者 | 实现者、评审者 | 使用者 |
| 写什么 | 哪里会出错、什么没验证、为什么这么取舍 | 怎么用 |
| 进静态站 | ❌ | ✅ |

**现在不写**：产品还没有可以「使用」的形态（`apps/app` 未落地）。
等托盘能跑起来、有一个真实可用的最小流程，再从这里开始写 ——
在那之前写的使用文档一定是错的。
