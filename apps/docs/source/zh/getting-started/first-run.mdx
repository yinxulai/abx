# 拖进去之后会发生什么

一次任务只有三步。每一步都能在面板上看见结果，不需要命令行。

## 第一步：把要给它看的东西拖进共享区

拖到**菜单栏图标**上，或拖到面板里的虚线区。列表里立刻多一行，标着「只读」。

拖进去的东西会：

- **变成立刻可见**：已经在跑的舱，下一次读目录时就能看见，**不需要重启舱**。
- **对全部舱只读**：agent 能读，改不了你递进去的原件。
- **保留原件**：优先建硬链接（秒级、不占空间），跨磁盘时回退为复制；重名自动加序号，**绝不覆盖**。
- **移除只解除共享**：从列表里移除，只是不再挂给舱，**不会删掉你的文件**。

<Callout title="共享区 ≠ 任务目录" type="note">
拖进托盘的东西进的是**共享区**（只读）。agent 要动手改的那个目录叫**任务目录**，
是起舱时选的，以可写方式挂进舱。两件事分开，是因为「给它看」和「让它改」的风险不一样。
</Callout>

## 第二步：点一个 agent 方块起舱

点面板顶部 claude 或 codex 的方块（名字在指针悬停或键盘聚焦时出现）：

- 方块的描边变成实线、右下角的点变成实心 —— 这就是**一个舱在跑**。头部没有计数：
  数量归管理面板，托盘面板只说在不在跑。
- 同一时刻点第二个 agent 是**再开一舱**，不是切换；再点已经在跑的 agent，是**聚焦**那一舱，不会重复启动。
- 舱里：任务目录可写、共享区只读、`/tmp` 可写且有大小上限，其余文件系统只读；以非 root 用户运行。
- agent 读到的配置是 **abx 现生成的那一份**，只有一扇门（气闸）和一个占位符。
  它看不到你本机那份配置，更看不到同目录里的登录凭据（见[配置是生成的，只读](/inside/config)）。
- agent 发出的第一句请求就带审计，目标域名不在白名单里会被当场拦下并留痕。

关掉 agent 进程，舱就**销毁**。一次性是设计，不是省事：写在启动项、cron、shell 配置里的东西留不下来。

## 第三步：把产物取回来

agent 交付的东西落在这一舱自己的**取回文件夹**里：`publish` 落地即**打开**，
不在面板上单独列一行 —— 面板上列出来的只有**共享文件**。

- 打开的是文件本身，不是「一个等待确认的条目」。
- 自动打开受后缀限制：`.html` / `.svg` / `.sh` 一律不自动打开。
- 「打开」是**给你看**，不是**替你执行**。
- 舱销毁后，取回文件夹仍然保留 —— 产物不能丢。

## 收尾：停止与退出

| 动作 | 发生什么 |
|---|---|
| 停止全部 | 在**管理面板**顶部；一次停掉全部舱，托盘继续运行 |
| 退出 | 停掉全部舱并退出应用；共享区、取回区、审计文件都留在原处 |

下次启动时，共享区里还是上次那些条目，取回区也不会被清空。
