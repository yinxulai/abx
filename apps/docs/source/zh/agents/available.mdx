当前清单里有 **{AGENT_COUNT} 个 agent**。名字、命令、配置落点、上游和状态都取自
`packages/contracts/source/agents.ts` —— **清单是唯一真相**，面板、配置生成与这份文档都从它读，

## 配置落点

abx 只为标着「生成」的文件写内容；标着「只登记」的文件不写、也不挂，列出来只为把配置面写全。

<table>
  <thead>

      <th>格式</th>
      <th>abx 做什么</th>
    </tr>
  </thead>
  <tbody>
    {AGENT_DOCS.flatMap((agent) =>
      agent.registeredFiles.map((file) => (
        <tr key={`${agent.id}-${file.path}`}>
          <td>{agent.label}</td>
          <td><code>{file.path}</code></td>
          <td>{file.format}</td>
          <td>{file.generated ? '生成并只读挂载' : '只登记，不生成也不挂载'}</td>
        </tr>

  </tbody>
</table>

生成出来的内容只有一扇门（气闸）和一个占位符，没有 `model` 字段；你本机那份配置与
同目录的登录凭据不会进舱。细节见[配置是生成的，只读](/inside/config)。

## 加一个 agent 是加数据

清单里的每条定义由展示信息、镜像、历史目录、配置模板与上游接线组成。新增一个 agent 的正常路径是
往清单里加一条，**不改会话编排、不改界面**。面板那一排、配置生成和这页表格都会跟着清单走。
