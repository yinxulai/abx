# abx 是什么

abx（airlock box，气闸）是一个 **macOS 托盘应用**。你把要给它看的目录或文件拖进托盘，点一个 agent，abx 就起一个**一次性隔离舱**，在里面跑 Claude Code、Codex 或 dsh。它能在舱里像在本机一样读代码、跑测试、写文件，但**拿不到你的真实凭据**，也**出不了白名单**。

它解决的是一个很具体的两难：

| 今天的选择 | 后果 |
|---|---|
| 把 API Key 直接交给 agent | 它能干完整活，但也能读 `~/.ssh`、`curl` 你的生产库、`rm -rf` |
| 不给凭据、不给目录 | 安全了，但它干不了活，等于没用 |

abx 的赌注是：这个二选一是假的。凭据可以留在舱外由气闸注入，目录可以只挂任务目录，出网可以只放白名单。agent 照样能干活，但它拿到的东西全是**借来的、带闸门的、留痕的**。

## 一次任务长什么样

```text
你把 repo/ 拖进托盘
        │
        ▼
  起一个一次性舱：repo/ 可写、共享区只读、配置只读
        │
        ▼
  舱内 agent ──请求──▶ 气闸（宿主）──▶ OSW（宿主）──▶ 真实供应商
        │                 │
        │                 └─ 校验舱令牌、出口白名单、替换占位符、记审计
        └─ 只拿到一个 baseUrl + 一个占位符
```

模型和密钥都配置在宿主上的 **OSW** —— 它已经把你手上的渠道收进一个本地地址。abx 不复制任何供应商配置，也不把密钥带进舱。气闸是舱的前门，OSW 是门后的调度中心。

## 它不是什么

- **不是另一套模型管理**。供应商、模型、路由、故障转移都在 OSW；abx 只负责舱、闸门与留痕。
- **不是虚拟机**。舱共用宿主内核，abx 不承诺防住内核级逃逸。
- **不是网络匿名工具**。出网 IP 仍然是你自己的。
- **不会拦住你主动递进去的秘密**。你把 `.env` 拖进共享区，agent 就能读到它。
- **不是跨平台工具**（V1 只做 macOS），也没有命令行形态。
