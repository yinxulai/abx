# 设计体系（令牌层）

这份文档是**颜色、字号、间距、圆角、状态表达**的唯一来源。托盘面板与管理面板共用它——
两个面板是同一个产品，不该各有一套观感。

令牌的实现落在 `packages/console/source/styles.css` 的 CSS 变量里。**改这份文档不等于改产品**，
两边必须一起动；下一节的距离审计就是用来抓「说了没做」的。

---

## 1. 三条原则

**1. 中性底，两处点缀。** 基色是中性灰（低彩度），只有**一个点缀色**和**一个危险色**。
不再加第三种色相——一旦允许，下一个状态就会再要一个颜色，几个月后「中性」只剩一句口号。

**2. 颜色永不单独承载信息。** 运行中不只是一个色块，还有实心形状与文字；危险不只是变红，
还有图标与措辞。色觉差异的用户必须同样能读懂状态。

**3. 边界分两档，因为它们承担的责任不同。** 装饰性分隔线可以很淡；
**用来识别一个控件的边界**（拖放区的虚线、输入框）必须 ≥ 3:1，否则它等于没画。

---

## 2. 颜色令牌

数值是实测结果，不是估的。比值按 WCAG 2.1 相对亮度计算。

### 深色

| 令牌 | 值 | 用在哪 | 实测对比度 |
|---|---|---|---|
| `--bg` | `#191A1C` | 面板底层 | — |
| `--surface` | `#232427` | 卡片 | — |
| `--raised` | `#2B2C2F` | 悬浮/活动块 | — |
| `--border` | `#35373B` | **装饰性**分隔线 | 1.30:1（不为信息负责，故豁免） |
| `--border-strong` | `#7E8288` | 有意义边界（拖放区、输入框） | surface **4.02:1** / bg **4.51:1** |
| `--text` | `#F2F3F4` | 正文 | bg **15.68:1** / surface **13.97:1** |
| `--text-muted` | `#9B9DA3` | 次要文字 | bg **6.42:1** / surface **5.72:1** |
| `--accent` | `#3FD9C6` | 运行中 / 主操作 | bg **9.91:1** / surface **8.83:1** |
| `--danger` | `#FF7A72` | 失败 / 被拒 | bg **6.87:1** |

### 浅色

| 令牌 | 值 | 用在哪 | 实测对比度 |
|---|---|---|---|
| `--bg` | `#FAFAFA` | 面板底层 | — |
| `--surface` | `#FFFFFF` | 卡片 | — |
| `--raised` | `#F1F1F2` | 悬浮/活动块 | — |
| `--border` | `#E2E2E5` | **装饰性**分隔线 | 1.29:1（豁免） |
| `--border-strong` | `#82848A` | 有意义边界 | surface **3.74:1** / bg **3.58:1** |
| `--text` | `#1A1B1D` | 正文 | bg **16.51:1** / surface **17.24:1** |
| `--text-muted` | `#5C5E65` | 次要文字 | bg **6.20:1** / surface **6.47:1** |
| `--accent` | `#0E8C80` | 图形（图标、状态点） | surface **4.13:1** |
| `--accent-deep` | `#0A7268` | **当文字用**，以及实心按钮底 | surface **5.80:1** |
| `--danger` | `#C0362C` | 失败 / 被拒 | surface **5.52:1** |

**为什么浅色下点缀色有两个值**：同一个色相在深底上够亮、在白底上就不够。
`#0E8C80` 当图形是够的（4.13 ≥ 3），当正文不够（< 4.5），所以正文与深色按钮底用 `#0A7268`。
**不要用 `--accent` 在浅色下写正文**——那是这份文档里最容易犯的错。

实心按钮的两组合法搭配（都 ≥ 4.5:1）：深色下 `accent` 底 + `#191A1C` 字（9.91:1）；
浅色下 `accent-deep` 底 + 白字（5.80:1）。

## 3. 字号与字重

英文与数字用 `Geist Variable`（回退 `-apple-system` / `SF Pro Text`），中文回退 `PingFang SC`，
等宽（路径、镜像引用、版本号、id）用 `Source Code Pro` → `SF Mono` → `ui-monospace`。

| 令牌 | 字号 | 行高 | 用在哪 |
|---|---|---|---|
| `--text-2xs` | 11 | 14 | 徽标、计数 |
| `--text-xs` | 12 | 16 | 次级说明 |
| `--text-sm` | 13 | 18 | agent 名、列表行 |
| `--text-base` | 14 | 20 | 正文 |
| `--text-lg` | 16 | 24 | 卡片标题 |
| `--text-xl` | 20 | 28 | 管理面板页面标题 |

**六档封顶**。字重只用 400 / 500 / 600——再多一档就不会有人分得清该用哪个。

---

## 4. 间距与圆角

间距是 **4 的倍数**：`2 / 4 / 6 / 8 / 12 / 16 / 20 / 24 / 32`。
唯一例外是 6（紧凑的图标与文字之间），因为它比 4 松、比 8 紧，正好是那一处的需要。

圆角：`--radius-sm: 4` / `--radius-md: 6` / `--radius-lg: 10`，徽标用 `999`（胶囊）。
沿用现有值——它们已经在真实渲染里验过，没有需要改的理由。

## 5. 状态怎么表达（与颜色无关的部分）

| 状态 | 表达 |
|---|---|
| 正在运行 | 实心块（`--accent`）+ 文字说明，不是只换颜色 |
| 可启动 | 描边块（`--border-strong` 虚线）+ 明显更高的对比，**不能看起来像禁用** |
| 未安装 / 不可用 | 中性块 + 一句「为什么」+ 一个动作（例如「构建镜像」） |
| 失败 / 被拒 | `--danger` + 图标 + 具体原因，**原因不能省** |

「未安装」与「失败」是两种不同的东西：前者是可预期的、有下一步；后者是出错了。
它们不该长得一样。

---

## 6. 两个面板的关系

同一个设计体系，两种密度：

- **托盘面板**（422 宽 = 卡片 366 + 左右各 28 留白）：上 icon 横向展开、下共享列表。
  只做两件事——快速打开已装 agent、查看共享内容。
- **管理面板**（独立窗口）：设置与管理。密度更高，用同一套令牌与字号档位。

管理面板里**必须能看出当前用的是哪个后端**（`docker` / `local`）。
`local` 不是沙箱，绝不能和 docker 长得一样——这是安全信息，不是外观偏好。

## 7. 怎么保证它没被违反

`~/.openclaw/workspace/skills/design-review-loop/scripts/audit.mjs`（零依赖 CDP 审计）
检查对比度、溢出、触控尺寸、字号与间距。**正文 < 4.5:1 视为失败**。

这份文档里的数值应当与 `styles.css` 一致；不一致时以**实测**为准，
然后回来改这份文档——不要让文档成为那个说假话的地方。

## 8. 已定的三件事（2026-10-23）

1. **图标用真实的品牌标识**，不用首字母。三家各做一个能认出来的形状；
   **Claude 的品牌橙 `#d97757` 保持原色，不压暗**——WCAG 明确豁免 logo，
   改第三方的品牌色等于改人家的标识。达标责任落在**容器**（方块必须是中性底），不在标识本身。
2. **点缀色就用青绿**（深 `#3FD9C6` / 浅 `#0E8C80` 与 `#0A7268`）。理由：技术感，且与危险红不冲突。
3. **明暗跟随系统，面板内不加开关**。少一个控件，也少一处要维护的状态。

### 连同定下的状态与结构

- **agent 名字永不随状态变淡**。「运行中」靠加强表达（更粗边框 + 实心点），不靠削弱「未运行」。
  原来的「10% 灰底 + 弱化文字」让最该点的那个看起来像禁用，这一条是在修那个。
- **措辞用动作词**：未运行「启动」、运行中「聚焦」。托盘里不出现「打开 ↗」——
  箭头暗示跳到别处，而这里是就地拉起。
- **托盘的「N 舱」胶囊去掉**：副标题已说「气闸在运行」，舱数是管理面板的职责。
- **未构建的 agent（dsh）照实显示**，用虚线 + 原因 + 下一步（构建镜像），不隐藏。
- **管理面板宽度待重算**：原定 1120 的理由是「审计流水是 7 列表格，窄了读不了」，
  而 7 列表格已经不在第一屏了（见 `functional-design.md §13`）。
  现在只有三块（header / agent 一排 / 共享列表），**不需要 1120，需要重新定一次**。
- **明暗、尺寸、字数都不改变行为**；托盘点击行为（未运行→启动并聚焦、运行中→聚焦、幂等）
  要等 session IPC 落地才算数。
